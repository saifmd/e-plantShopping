# Paradise Nursery

Paradise Nursery is a modern React-based plant shopping experience built with Vite and Redux Toolkit. The app features a welcoming landing page, a curated plant catalog, and a shopping cart experience for browsing and selecting indoor plants.

## Features

- Beautiful landing page with a polished nursery theme
- Categorized plant listings for different plant types
- Add-to-cart interactions powered by Redux
- Cart quantity tracking and product management
- Responsive and visually appealing UI

## Tech Stack

- React
- Vite
- Redux Toolkit
- React Redux
- CSS for styling

## Project Structure

- src/App.jsx - Main app layout and landing experience
- src/ProductList.jsx - Plant catalog and product grid
- src/CartSlice.jsx - Cart state and reducers
- src/store.js - Redux store configuration
- src/assets - Static assets used by the app

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal to view the app.

## Available Scripts

- npm run dev - Start the Vite development server
- npm run build - Build the project for production
- npm run preview - Preview the production build locally
- npm run deploy - Deploy the app to GitHub Pages

## Deployment

This project is configured for GitHub Pages deployment using the `gh-pages` package.
